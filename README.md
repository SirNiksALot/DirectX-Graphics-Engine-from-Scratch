# DirectX Engine

A lightweight C++ DirectX engine project focused on building a clean rendering foundation, window management, and game loop architecture.

## Demo

[Watch the demo video](https://github.com/user-attachments/assets/7beedee3-8502-4f95-9932-e69a72cf2169)

## Overview

This project is designed as a practical DirectX learning and experimentation engine. It includes modular components for:

- engine core setup and initialization
- window/display management
- graphics device and rendering pipeline
- shader and asset integration
- game loop orchestration

## Project Structure

- `DirectX Engine/` — main engine project files
- `DX3D/` — engine source and include directories
- `Game/` — application entry point and gameplay logic
- `Assets/Shaders/` — shader source files

## Getting Started

1. Open the solution file in Visual Studio.
2. Set the build configuration to x64.
3. Build the solution.
4. Run the project to launch the engine.

## Requirements

- Windows
- Visual Studio 2022
- DirectX compatible graphics hardware
- C++ desktop development tools

## Notes

This project is intended as a base for learning DirectX rendering, engine architecture, and C++ graphics development.
